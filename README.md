# 🕐 PocketWatch> Annotation-based date validation for Java. Stop writing repetitive validation code.[![Java 21](https://img.shields.io/badge/Java-21-blue.svg)](https://openjdk.org/projects/jdk/21/)[![License](https://img.shields.io/badge/License-Apache%202.0-green.svg)](LICENSE)---## The Problem```java// 50+ lines of validation in every controllerif (date == null) return error();try { LocalDate.parse(date); } catch (Exception e) { return error(); }if (date.isBefore(now())) return error();// ... repeat for every field ...```## The Solution```javapublic class BookingRequest {    @ValidDate    @FutureDate    @DateRange(minDaysFromNow = 1, maxDaysFromNow = 365)    private String checkInDate;        @ValidDate    @PlusDays(from = "checkInDate", days = 1)    private String checkOutDate;}// ValidateValidationResult result = PocketWatchValidator.validate(request);```---## Quick Start### Maven```xml<dependency>    <groupId>io.pocketwatch</groupId>    <artifactId>pocket-watch-validator</artifactId>    <version>1.0.0-SNAPSHOT</version></dependency>```### Basic Usage```javaimport io.pocketwatch.annotations.*;import io.pocketwatch.validator.*;public class Event {    @ValidDate(pattern = "yyyy-MM-dd")    @PastDate    private String birthDate;}ValidationResult result = PocketWatchValidator.validate(event);if (!result.isValid()) {    result.getErrors().forEach(System.out::println);}```---## Annotations| Annotation | Description ||------------|-------------|| `@ValidDate` | Validates format || `@PastDate` | Must be in past || `@FutureDate` | Must be in future || `@DateRange` | Between min/max days from now || `@PlusDays` | Auto-calculate from another field || `@ValidTimeZone` | Validates timezone |---## Examples### Hotel Booking```java@ValidDate@DateRange(minDaysFromNow = 1, maxDaysFromNow = 365)private String checkInDate;```### Event Registration```java@ValidDate@FutureDate@DateRange(minDaysFromNow = 7, maxDaysFromNow = 90)private String eventDate;```### Leave Request```java@ValidDate@PlusDays(from = "startDate", days = 7)private String endDate;```---## Date PatternsUse `DatePattern` constants:```javaDatePattern.ISO_DATE         // "2025-11-05"DatePattern.US_DATE          // "11/05/2025"DatePattern.EU_DATE          // "05/11/2025"DatePattern.DB_TIMESTAMP     // "2025-11-05 14:30:00"// ... 16 more patterns```---## PocketWatch API (Optional)Fluent date utilities:```javaString result = PocketWatch.parse("2025-11-05")    .plusDays(7)    .toZone("America/New_York")    .format("yyyy-MM-dd");// Convert to standard Java typesLocalDate date = PocketWatch.parse("2025-11-05").toLocalDate();```---## Why PocketWatch?✅ Reduces validation from 50 lines to 1 annotation  ✅ Works with String dates (legacy systems, REST APIs)  ✅ SOLID architecture + Functional programming  ✅ No library lock-in (converts to standard Java types)  ✅ Production-ready with comprehensive tests  ---## Building```bashgit clone
