# 🕐 PocketWatch> A modern Java date/time library with annotation-based validation and operations.[![Java Version](https://img.shields.io/badge/Java-21-blue.svg)](https://openjdk.org/projects/jdk/21/)[![License](https://img.shields.io/badge/License-Apache%202.0-green.svg)](LICENSE)## ✨ Features- 🎯 **Clean API**: Fluent, immutable date/time operations- 🔍 **Annotation-based Validation**: Validate dates with zero boilerplate- 🚀 **Functional Programming**: Higher-order functions and composition- 🏗️ **SOLID Design**: Production-quality architecture- 🔧 **Java 21+**: Modern Java features - 📦 **Modular**: Use only what you need## 🚀 Quick Start### Maven Dependency```xml<dependency>    <groupId>io.pocketwatch</groupId>    <artifactId>pocket-watch-validator</artifactId>    <version>1.0.0-SNAPSHOT</version></dependency>```### Basic Usage```java// Parse and format datesPocketWatch date = PocketWatch.parse("2025-11-04");String formatted = date.format("dd MMM yyyy");  // "04 Nov 2025"// Date operationsPocketWatch nextWeek = PocketWatch.now()    .plusDays(7)    .plusHours(2)    .toZone("America/New_York");// Validation with annotationspublic class Event {    @ValidDate(pattern = "yyyy-MM-dd")    @FutureDate    private String startDate;        @PlusDays(from = "startDate", days = 7)    @ValidDate    private String endDate;}Event event = new Event();event.setStartDate("2025-12-25");ValidationResult result = PocketWatchValidator.validate(event);if (!result.isValid()) {    result.getErrors().forEach(System.out::println);}```## 📚 Modules| Module | Description | Status ||--------|-------------|--------|| `pocket-watch-core` | Core date/time operations | ✅ In Progress || `pocket-watch-annotations` | Annotation definitions | ✅ In Progress || `pocket-watch-validator` | Runtime validation engine | ✅ In Progress || `pocket-watch-processor` | Compile-time code generation | 🔮 Future |## 🎯 Roadmap### Phase 1: Validation (Current)- [x] Project setup- [ ] Core date/time API- [ ] Basic annotations (@ValidDate, @PastDate, @FutureDate)- [ ] Validation engine- [ ] Comprehensive tests- [ ] Documentation### Phase 2: Advanced Validation- [ ] @DateRange annotation- [ ] @PlusDays/@PlusHours calculations- [ ] @TimeZone validation- [ ] Custom validators- [ ] Validation groups### Phase 3: Code Generation (Lombok-style)- [ ] Annotation processor- [ ] Auto-generate getter methods- [ ] Bytecode manipulation (optional)- [ ] IDE plugin support## 🏗️ Building from Source```bash# Clone repositorygit clone https://github.com/kenduraghav/pocket-watch.gitcd pocket-watch# Build all modulesmvn clean install# Run testsmvn test# Build without testsmvn clean install -DskipTests```## 🤝 ContributingContributions are welcome!
